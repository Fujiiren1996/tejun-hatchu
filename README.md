# テジュン食堂 発注書アプリ（STEP1）

スマホで「発注したい数」を入力 → 業者ごとのPDFを作成 → そのまま共有（LINE等）するためのアプリです。
サーバー・アカウント・通信は不要。すべて端末内で動きます。

## ファイル構成

```
発注管理アプリ/
├─ index.html        … 画面
├─ styles.css        … 見た目（スマホ専用・色分け）
├─ app.js            … 動作＋食材/業者データ（ここを編集して食材を増やせます）
└─ lib/              … PDF生成ライブラリ（オフライン用に同梱）
   ├─ jspdf.umd.min.js
   └─ html2canvas.min.js
```

## 食材・業者の増やし方（コード不要レベル）

`app.js` の先頭にある **設定** だけ書き換えます。

- お店の名前 … `SHOP_NAME`
- お店の電話番号（任意）… `SHOP_TEL`（入れるとPDFに表示。空ならPDFに出ません）
- 業者 … `VENDORS`（上から表示順・色）
- 食材 … `ITEMS`（`name`＝品名、`vendor`＝どの業者か、`unit`＝単位（任意・空でOK））

食材を1つ足す例：

```js
{ id: "moyashi", name: "もやし", vendor: "yaoya", unit: "" },
```

- `id` は保存に使う「変わらない名札」です。**重複しない英数字**にし、一度決めたら変えないでください
  （変えると、その品目の当日入力だけ 0 に戻ります）。
- 業者を増やすときは `VENDORS` に1行足し、その `id` を食材の `vendor` に使います。色は `bg`（薄い背景）/`accent`（見出し・ボタン）を指定。

> STEP2 で「アプリ画面から食材を追加・並べ替え」できるようにする予定です。それまではここを編集します。

## できること（STEP1）

- 発注数の入力（− / ＋ / 数字直接入力）。入力した品目は左に色の線が付きます。
- 業者ごとに自動でまとまり、色分け表示。上部の目次タップでジャンプ。画面上部に「本日の発注：合計○品／○業者」を表示。
- 各業者の「📄 発注書を作る（○品）」… **送信前プレビュー**で内容を確認 →
  - 「共有・保存（PDF）」… その業者だけの正式な発注書PDFを作成し、共有シート（LINE・メール等）へ。
  - 「テキストで送る」… 発注内容を文章で共有/コピー（LINE貼り付け用の確実な手段）。
- 自動保存（端末内）。閉じても消えず、開くと続きから復元。
- 発注日／納品希望日を設定（PDFにも記載。納品希望日はPDFで赤く強調）。
- 日付が変わると自動で新しい発注画面に（前日分は履歴として端末内に残ります）。

## スマホで使うには

ローカルのファイルをそのままスマホで開くことはできないため、次のいずれかで「URL」にして使います。

1. 静的ホスティングに置く（GitHub Pages / Netlify / Vercel など）
2. 出てきたURLをスマホで開く
3. Safari/Chrome の「ホーム画面に追加」でアプリのように使う
